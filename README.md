# 🥖 Информационная система «Пекарня»

Веб-приложение для внутреннего учёта небольшой пекарни: управление **сотрудниками**, **ингредиентами** (сырьём) и **пользователями** системы с авторизацией по ролям.

Это веб-версия ранее существовавшего настольного приложения для учёта в пекарне.

---

## Что это и для чего

Система автоматизирует внутренний учёт пекарни и заменяет ручное ведение данных:

- **Сотрудники** — кадровый состав (ФИО, должность).
- **Ингредиенты** — сырьё для выпечки (наименование, единица измерения, количество на складе) с привязкой к **ответственному сотруднику**.
- **Пользователи** — учётные записи для входа с разделением прав.

Доступ разграничен по ролям:

- **Администратор** — полный доступ ко всем разделам (ингредиенты, сотрудники, пользователи).
- **Пользователь** — работает только с ингредиентами (и видит список сотрудников для выбора ответственного).

---

## Возможности

- 🔐 Авторизация по логину/паролю (JWT), пароли хранятся в виде bcrypt-хеша.
- 🧂 Учёт ингредиентов — добавление, редактирование, удаление, поиск по названию, выбор ответственного.
- 👷 Учёт сотрудников — CRUD (только администратор).
- 👤 Управление учётными записями и ролями (только администратор).
- 🛡️ Разграничение доступа на уровне API (Guards + роли) и интерфейса (скрытие разделов).

## Быстрый старт

Нужен только установленный **Docker**.

```bash
docker compose up -d --build
```

Открыть **http://localhost:5173** и войти под учётной записью по умолчанию: **`admin` / `admin`**.

Подробности, команды и устранение неполадок — в [ЗАПУСК.md](ЗАПУСК.md).

## Технологии (кратко)

**Клиент:** React + Redux Toolkit + Ant Design + React Router (Vite, TypeScript)
**Сервер:** NestJS + Prisma + JWT (TypeScript)
**База данных:** MySQL · **Инфраструктура:** Docker Compose

Подробнее — [ТЕХНОЛОГИИ.md](ТЕХНОЛОГИИ.md).
